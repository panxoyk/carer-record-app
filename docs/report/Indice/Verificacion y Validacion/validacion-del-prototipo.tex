\subsection{Validación del prototipo}

La validación con personal médico y de enfermería permanece pendiente. Las maquetas y el protocolo de usabilidad definidos en el Perfil de Diseño constituyen el instrumento previsto, pero no se dispone de participantes, observaciones, tiempos de tarea ni puntajes SUS que permitan concluir aceptación o utilidad clínica~\cite{ref_brooke_sus}.

Para Hito 4 se propone ejecutar, como mínimo, las siguientes actividades:

\begin{itemize}
    \item pruebas unitarias y de integración para autenticación, pacientes, notas, audio y cierre de casos;
    \item pruebas de integración hospitalaria simulada con recursos FHIR y mensajes HL7v2 sintéticos, incluyendo casos válidos, inválidos y repetidos;
    \item pruebas de autorización que comprueben respuestas denegadas para sesiones ausentes, vencidas o sin permisos;
    \item pruebas del ASR con vocabulario clínico, ruido ambiental y distintos dispositivos, midiendo errores y latencia;
    \item pruebas de seguridad para carga y descarga de audio, gestión de secretos y aislamiento de datos;
    \item pruebas de recuperación y sincronización frente a pérdida de conectividad;
    \item ejecución del protocolo de usabilidad con personal asistencial y registro de completitud, tiempo, errores y SUS;
    \item revisión clínica de transcripciones, categorías y borradores utilizando exclusivamente casos sintéticos durante el alcance académico.
\end{itemize}

La aceptación del prototipo final requerirá evidencia reproducible de estas pruebas. Hasta entonces, los resultados de Hito 3 deben interpretarse como validación técnica preliminar de componentes y no como validación clínica del sistema.
