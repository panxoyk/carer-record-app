\subsection{Restricciones}

\begin{itemize}
    \item Solo usuarios autenticados y autorizados pueden acceder a información clínica o ejecutar acciones sobre ella.
    \item El desarrollo académico debe utilizar datos sintéticos y ambientes separados de cualquier infraestructura clínica real.
    \item Todo contenido producido por IA debe presentarse como preliminar y permanecer sujeto a revisión humana.
    \item El audio y la transcripción sin confirmar permanecen en el dispositivo; las notas confirmadas se envían a los servicios de Carer-Record.
    \item La demostración utiliza la FCE simulada FHIR R4 en Docker con datos sintéticos, sin depender del acceso a un sistema hospitalario real.
    \item La solución busca reducir la carga operativa del personal asistencial; la usabilidad se evalúa mediante el protocolo definido.
\end{itemize}
