\subsection{Requisitos Funcionales}

Los requisitos funcionales describen las capacidades comprometidas para la versión final V4 de Carer-Record. Se expresan con independencia de tecnologías concretas y no constituyen una afirmación sobre resultados de validación.

\subsubsection*{\textbf{RF-01} - Integración con fuentes de información hospitalaria}

El sistema debe obtener información de pacientes y hospitalizaciones desde fuentes hospitalarias autorizadas y vincularla con el contexto correspondiente de Carer-Record.

\subsubsection*{\textbf{RF-02} - Consulta del contexto clínico}

El sistema debe permitir localizar pacientes y consultar, para las hospitalizaciones accesibles, sus antecedentes, eventos y contexto de hospitalización autorizados.

\subsubsection*{\textbf{RF-03} - Visualización de la bitácora asistencial}

El sistema debe presentar cronológicamente los eventos y notas de contexto asociados a una hospitalización, distinguiendo la información procedente de fuentes externas de la registrada en Carer-Record.

\subsubsection*{\textbf{RF-04} - Registro de notas de contexto}

El sistema debe permitir redactar notas de contexto por texto o dictado, revisar su contenido y confirmar su registro; la nota confirmada debe quedar asociada a su autor y a una hospitalización autorizada.

\subsubsection*{\textbf{RF-05} - Transcripción de dictados}

El sistema debe convertir dictados a texto editable para que la persona autora pueda revisarlo y corregirlo antes de confirmar una nota.

\subsubsection*{\textbf{RF-06} - Asistencia para la redacción}

El sistema debe ofrecer asistencia para mejorar la redacción de una nota sin cambiar el significado del contenido de origen. La persona autora decide si acepta, edita o descarta la propuesta.

\subsubsection*{\textbf{RF-07} - Resúmenes asistidos}

El sistema debe generar resúmenes de eventos y notas de una hospitalización para un período seleccionado, usando únicamente fuentes autorizadas. El resumen debe presentarse para revisión y no debe publicarse como nota ni escribirse en la FCE.
