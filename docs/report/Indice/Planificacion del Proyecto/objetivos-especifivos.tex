\subsection{Objetivos Específicos}

Los objetivos específicos (OE) organizan el trabajo técnico y de diseño necesario para avanzar desde el prototipo parcial de Hito 3 hacia el prototipo final.

\begin{itemize}
    \item \textbf{OE1.} Establecer un flujo de ingesta y normalización de datos sintéticos mediante la simulación de sistemas hospitalarios y el uso de estándares de interoperabilidad vigentes, sin depender de información real.

    \item \textbf{OE2.} Desarrollar el procesamiento de texto clínico mediante ASR, NER y un LLM, manteniendo revisión humana antes de publicar resultados.

    \item \textbf{OE3.} Diseñar e implementar la aplicación móvil, la autenticación y el flujo HITL para que la información sea accesible únicamente a personal autorizado.

\end{itemize}
