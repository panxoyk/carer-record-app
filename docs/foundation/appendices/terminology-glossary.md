# Glosario de terminología

| Término                 | Uso en esta fundación                                                                                                                                                                                                                                           |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ADR                     | Registro de una decisión arquitectónica, sus alternativas y consecuencias. Aceptada no significa implementada.                                                                                                                                                  |
| Anonimización           | Transformación que impide razonablemente identificar a una persona según un contexto y estándar definidos. No se atribuye a NER/tokenización en este proyecto.                                                                                                  |
| ASR                     | Automatic Speech Recognition; conversión de audio a texto. En este prototipo se decide local.                                                                                                                                                                   |
| Auditoría               | Registro durable de una acción relevante, actor, tiempo, objetivo y resultado. Se separa de logs de depuración.                                                                                                                                                 |
| Cache hit               | Reutilización de una entrada cuya clave, versión, autorización y vigencia coinciden exactamente.                                                                                                                                                                |
| ClinicalEvent           | Entidad interna de evento clínico con tipo, instante y detalles; no equivale a cualquier recurso FHIR. Evidencia: `app/lib/domains/clinical_event/domain/entities/clinical_event.dart:1-23`.                                                                    |
| Correlation ID          | Identificador opaco para seguir una operación entre componentes sin incluir datos clínicos.                                                                                                                                                                     |
| Datos sintéticos        | Datos creados artificialmente, sin origen en una persona real. Cambiar nombres de datos reales no los vuelve sintéticos.                                                                                                                                        |
| Desidentificación       | Conjunto contextual de técnicas para reducir identificación. No es sinónimo automático de anonimización.                                                                                                                                                        |
| Edge Function           | Función servidor en el runtime de Supabase usada como frontera HTTP y, cuando corresponde, de secretos.                                                                                                                                                         |
| FHIR                    | Estándar de intercambio sanitario. Aquí se usa solo en la frontera, con versión y perfiles explícitos.                                                                                                                                                          |
| Frontera anticorrupción | Adapter que traduce y valida un modelo externo antes de ingresarlo al dominio interno.                                                                                                                                                                          |
| Idempotencia            | Propiedad por la que repetir un comando con la misma identidad no duplica el efecto de negocio.                                                                                                                                                                 |
| IPS                     | Información personal sensible, usada como categoría conservadora de ingeniería; la clasificación jurídica queda pendiente.                                                                                                                                      |
| NER                     | Named Entity Recognition; detección probabilística de entidades en texto. Puede omitir identificadores y no anonimiza.                                                                                                                                          |
| Outbox transaccional    | Registro de mensajes en la misma transacción que la mutación de negocio para publicarlos después con retry. No garantiza exactamente-una-vez por sí solo.                                                                                                       |
| Patient                 | Entidad interna de persona paciente; contiene identificadores y datos sensibles (`app/lib/domains/patient/domain/entities/patient.dart:1-20`).                                                                                                                  |
| Permiso                 | Capacidad versionada para ejecutar una operación. No se confunde con rol, que agrupa o recibe permisos.                                                                                                                                                         |
| PHI                     | Información de salud identificable. Se usa conservadoramente y no como conclusión legal sobre jurisdicción.                                                                                                                                                     |
| Practitioner            | Cuenta/perfil profesional o administrativo asociado a Auth. En el baseline, rol y estado estaban tipados en Postgres (`supabase/migrations/20260910000000_initial_clinical_schema.sql:4-14`; `supabase/migrations/20260910010000_auth_administration.sql:1-5`). |
| Procedencia             | Metadatos que permiten conocer origen, versión, transformación y parámetros de un artefacto sin copiar su contenido.                                                                                                                                            |
| Prototipo académico     | Sistema experimental con datos sintéticos, sin afirmación de aptitud clínica, cumplimiento o producción.                                                                                                                                                        |
| RLS                     | Row Level Security de Postgres; autoridad de acceso a filas en Supabase.                                                                                                                                                                                        |
| Service Role            | Credencial privilegiada servidor que evita RLS. Nunca pertenece al cliente móvil.                                                                                                                                                                               |
| Snapshot de resumen     | Derivado inmutable de fuentes y ventana identificadas, con versión de modelo/prompt y procedencia.                                                                                                                                                              |
| Spike                   | Experimento acotado para reducir incertidumbre; produce evidencia y una recomendación, no una feature.                                                                                                                                                          |
| Síntesis                | Texto derivado que condensa eventos. No sustituye eventos fuente ni constituye recomendación clínica.                                                                                                                                                           |
| Tokenización reversible | Sustitución de entidades por tokens y conservación separada de un mapa para restaurarlas bajo autorización. La salida sigue siendo sensible.                                                                                                                    |
| Turno                   | Jornada, asignación o handoff operacional. Está fuera de alcance y no debe confundirse con ventana temporal.                                                                                                                                                    |
| Ventana temporal        | Intervalo semiabierto `[desde,hasta)` y zona horaria usados para seleccionar fuentes de un resumen.                                                                                                                                                             |

## Términos que deben evitarse sin calificación

- “Anónimo”: usar solo si existe evaluación contextual de reidentificación.
- “Cumple”: nombrar estándar, alcance, evaluador, fecha y evidencia; no aplica al prototipo académico.
- “Seguro”: describir control y riesgo residual concreto.
- “FHIR compatible”: enumerar versión, recurso, perfil, operación y fixtures soportados.
- “Validado”: indicar si fue validación técnica, de usuario, clínica o regulatoria.
- “Tiempo real”: informar métrica y percentil en hardware/entorno definido.
